# 如何獲取非正式成績單 (Unofficial Academic Transcript)
**步驟 1：** 登入 [MyPortal](https://myportal.ln.edu.hk/web/lingnan/academicmatters)。
![](img/local_internship/Academic_Transcript_Printing_Guide_1.png)
**步驟 2：** 點擊 **"Academic Transcript"**。
![](img/local_internship/Academic_Transcript_Printing_Guide_2.png)
**步驟 3：** 在「Transcript Level」(成績單級別) 選擇「Undergraduate」(本科)，並點選「Web Transcript」(網頁版成績單)，然後按提交。
![](img/local_internship/Academic_Transcript_Printing_Guide_3.png)
**步驟 4：** 進入網頁後，請按 Ctrl + P (Windows) 或 Command (⌘) + P (Mac) 進行列印。

注意：網上成績單為 A3 尺寸，請準備一個 A3 文件夾存放。
