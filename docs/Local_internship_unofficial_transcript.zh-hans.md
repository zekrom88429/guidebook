# 如何获取非正式成绩单 (Unofficial Academic Transcript)
**步骤 1：** 登入 [MyPortal](https://myportal.ln.edu.hk/web/lingnan/academicmatters)。
![](img/local_internship/Academic_Transcript_Printing_Guide_1.png)
**步骤 2：** 点击 **"Academic Transcript"**。
![](img/local_internship/Academic_Transcript_Printing_Guide_2.png)
**步骤 3：** 在「Transcript Level」(成绩单级别) 选择「Undergraduate」(本科)，并点选「Web Transcript」(网页版成绩单)，然后按提交。
![](img/local_internship/Academic_Transcript_Printing_Guide_3.png)
**步骤 4：** 进入网页后，请按 Ctrl + P (Windows) 或 Command (⌘) + P (Mac) 进行列印。

注意：网上成绩单为 A3 尺寸，请准备一个 A3 文件夹存放。
