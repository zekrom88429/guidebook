# How to get an Unofficial Academic Transcript
**Step 1:** Log in to [MyPortal](https://myportal.ln.edu.hk/web/lingnan/academicmatters).
![](img/local_internship/Academic_Transcript_Printing_Guide_1.png)
**Step 2:** Click on **"Academic Transcript."**
![](img/local_internship/Academic_Transcript_Printing_Guide_2.png)
**Step 3:** Select "Undergraduate" in the _Transcript Level_ and "Web Transcript". then click submit.
![](img/local_internship/Academic_Transcript_Printing_Guide_3.png)
**Step 4:** When you see the website please click Crtl + P (Windows)/ Command (⌘) + P (Mac)

Note: The online transcript is A3 size, so please bring an A3 folder
