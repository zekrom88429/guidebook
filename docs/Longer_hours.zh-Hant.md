大學裏最常見的迷思之一，就是以為高GPA需要不斷溫習。

雖然學術表現對獎學金、交換生計劃和深造等機會至關重要，但優異的成績往往是有效規劃和明智決策的成果，而不是無休止地温習。
以下五個習慣可以提供幫助。

## 1.在學習內容前先研究評核方式

在深入閱讀講課投影片之前，先檢視評核分佈和評分準則。

了解課程的評核方式有助你分配心力。有些學生花費數小時準備考試，卻忽略了期末成績佔比重、能帶來寶貴分數的課業、課堂參與或演示。

評分準則同樣重要。與其只專注於完成功課，不如專注於評分準則所獎勵的標準。它通常最能清楚指出及格與優秀作業的分別。

## 2.盡早練習題目

許多學生直到溫習週才嘗試歷屆試卷題目。到那時，要有效找出並解決弱點往往已經太遲。

相反地，應在整個學期中持續練習。一個實用的目標是為每門課程每週至少完成一道歷屆試卷題目。

規律的練習有助於及早發現弱點、熟悉考試題型，並在考試期開始前建立充足的信心。

學生可利用圖書館的[歷屆題目](https://www.library.ln.edu.hk/en/collection/digital/examdb)。

## 3. 走在死線之前

大學裏其中一個最大的挑戰，是同時應付多個死線。

在每個學期開始時，將所有作業、演示、專題、小測驗和考試記錄在記事本或甘特圖中。這有助於及早識別繁忙時段，避免最後關頭才手忙腳亂。

提早開始工作也能創造機會尋找意見回饋、釐清疑難並提升作品質素。許多學生失分並非因為能力不足，而是因為開始得太遲。

### 4. 盡早開展 Group Project

小組專題往往因為太遲開始規劃而變得壓力重重。

組別一組成，便應建立通訊渠道、分配職責，並在官方死線前設定內部期限。定期檢視有助於在問題變得嚴重之前將其解決。

成功的小組專題通常源於清晰的期望、及早協調和持續溝通。

### 5. 使用人工智能獲取意見回饋

在適當使用下，人工智能可以成為寶貴的學習工具。

親自完成初稿後，可利用人工智能找出弱點、建議改進方法，或提供更佳回覆的範例。將你的作品與更佳的範例作比較，可以揭示需要改進的地方，並助你產出更高質素的習作。

然而，人工智能應被視為意見回饋的來源，而非權威。評分者是講師而非人工智能，因此評核標準和課程要求應永遠放在首位。

### 最後想法

高GPA並非單純靠溫習更長時間就能取得。它往往是理解課程評核方式、持續準備、有效管理死線以及及早尋找意見回饋的成果。

透過策略性地工作而非無休止地埋苦讀，你既能取得優異的學業成績，又能抽空體驗大學裏難忘的經歷。高GPA應該是高效工作的副產品，而不是犧牲大學生活其他一切所換取的代價。
